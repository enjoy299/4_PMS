# 导出测试文档到 05_export

## 命名规则

05_export 目录下所有文件遵循统一命名格式：

```
{需求编号}-{模块名}-测试点+测试用例_{时间}.xlsx
```

### 需求编号

- 从 `inputs/requirements/` 下的需求文档文件名中提取
- 补零到两位数字

| 需求文档 | 编号 |
|----------|------|
| `7、知识管理.md` | `07` |
| `11、工业APP.md` | `11` |

### 完整示例

```
05_export/
├── 知识管理/
│   └── 07-知识管理-测试点+测试用例_20260902_1654.xlsx
└── 工业APP/
    └── 11-工业APP-测试点+测试用例_20260903_1112.xlsx
```

## Excel 文件结构

每个 Excel 文件包含两个 Sheet，格式严格参照参考样例：
`output/05_export/工业APP/11-工业APP-测试点+测试用例_20260903_1041.xlsx`

详细字段定义和样式规范请参见 skill: `test-doc-format`

### Sheet 1: 测试点（8 列）

| 列 | 字段名 | 说明 | 示例 |
|----|--------|------|------|
| A | 测试点编号 | TP-{ID前缀}-{三位序号}（未拆分子模块时为 TP-{模块名}-{三位序号}） | TP-知识管理-分类管理-001 |
| B | 模块 | 实际功能模块名称 | 分类管理 |
| C | 需求来源 | 需求编号引用 | CAT-01 |
| D | 测试维度 | 正向功能/异常输入/边界值/状态流转/权限控制 | 正向功能 |
| E | 测试点描述 | 简洁描述测试目标 | 未选中分类时新建一级分类 |
| F | 优先级 | P0/P1/P2 | P0 |
| G | 是否依赖确认 | 是/否 | 否 |
| H | 备注 | 补充说明，无则填"-" | 核心流程 |

### Sheet 2: 测试用例（13 列）

| 列 | 字段名 | 说明 | 示例 |
|----|--------|------|------|
| A | 用例ID | TC-{ID前缀}-{三位序号}（未拆分子模块时为 TC-{模块名}-{三位序号}） | TC-知识管理-分类管理-001 |
| B | 模块 | 所属子模块 | 分类管理 |
| C | 需求来源 | 对应的需求编号 | CAT-01 |
| D | 测试点ID | 关联的测试点编号 | TP-知识管理-分类管理-001 |
| E | 用例标题 | 简洁描述测试目标 | 验证新建分类功能 |
| F | 优先级 | P0/P1/P2 | P0 |
| G | 用例类型 | 正向/异常/边界/权限/状态/配置/数据一致性 | 正向 |
| H | 前置条件 | 执行前必须满足的条件 | 已登录系统 |
| I | 测试数据 | 具体、脱敏、可替换的数据 | 分类名称：测试分类A |
| J | 操作步骤 | 编号列出，每步一个动作 | 1. 点击新建... |
| K | 预期结果 | 可观察、可判断的结果 | 1. 分类创建成功... |
| L | 清理动作 | 用例执行后的数据清理 | 删除创建的测试分类 |
| M | 备注 | 补充说明 | - |

### 数据来源

| Sheet | 数据来源 |
|-------|----------|
| 测试点 | `output/03_design/test_points/{业务模块名}/*-测试点.md` |
| 测试用例 | `output/03_design/test_cases/{业务模块名}/*-用例.md` |

> `{业务模块名}` 与 `output/02_split_requirements/` 子目录同名（如“知识管理”“工业APP”）。详见 skill: `design-test-cases` 的“目录约定（强制）”。

## 导出步骤

1. **确定需求编号**：读取 `inputs/requirements/` 中对应模块的文件名，提取数字前缀
2. **定位业务模块子目录**：`output/03_design/test_points/{业务模块名}/` 与 `output/03_design/test_cases/{业务模块名}/`
3. **读取测试点**：按 MODULE_CONFIG 中配置的 stem 列表解析对应文件的 Markdown 表格
4. **读取测试用例**：同上，解析 13 字段竖排属性表格
5. **去重**：按 ID 去重（多表格段落可能有重复行）
6. **生成 Excel**：写入两个 Sheet，应用表头样式
6. **保存**：按命名规则保存到 `output/05_export/{模块名}/`

## 执行脚本

```bash
# 导出指定模块（推荐，使用通用脚本）
python scripts/export_module_excel.py 工业APP
python scripts/export_module_excel.py 知识管理
python scripts/export_module_excel.py 项目管理
python scripts/export_module_excel.py 项目详情管理

# 知识管理专用脚本（已弃用，保留向后兼容）
python scripts/export_km_excel.py
```

## 注意事项

- 测试点和测试用例**合并在同一个 Excel**中，不分开导出
- 编号必须与需求文档一致，不使用顺序编号（01, 02...）
- 时间戳格式：`%Y%m%d_%H%M`
