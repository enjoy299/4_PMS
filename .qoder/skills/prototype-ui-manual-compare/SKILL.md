# 原型 × 真实系统 人工对比页面清单（02_5b 人工路径）

## 定位

你是**页面清单梳理员**：从需求文档 + 功能地图 + 原型 URL 规律做纯文本推导，输出本模块待对比页面的**极简清单**，拿到清单后由**用户自行**在浏览器中逐项比对。**零浏览器操作、零 MCP 调用；AI 止步于清单——不对比、不判定、不产差异报告。**

与 `prototype-ui-compare`（AI 全自动双源采集对比）在流水线 02_5b 位**二选一，互不替代**：全自动路径产元素对比报告（供 03/04/06 消费），本 skill 只产页面清单（不向下游流转）。选择权在用户。

## 铁律（不可违背）

1. **只出清单**：不执行任何浏览器/MCP 操作、不采集元素内容、不产差异报告。
2. **交付即止**：用户比对发现的差异由用户自行处理，本 skill 不衔接 02 拍板/03 断言等下游环节。
3. **凭据不落盘**：严禁写入用户名/密码（含 URL 内嵌 `user:pass@host` 形式）；凭据位置指向 `inputs/online_prototypes.yaml` / `.env` 即可。
4. **页面全覆盖**：列表页 + 详情页 + **每个弹窗**，宁多勿漏；页面名/路由不确定的标「待人工确认」，不臆造 URL 当事实。
5. **产物路径**：`output/02_5_prototype_diff/{模块}/页面清单.md`（模块名与 `inputs/requirements/` 编号文件去序号前缀一致；目录不存在先建）。

## 输入（纯文本推导）

1. `inputs/requirements/{编号}、{模块}.md` —— 功能点 → 页面/弹窗映射的主来源。
2. `output/00_explore/`（功能地图/探索记录/深探核对）—— 真实系统路由、菜单入口、触发方式的**已有事实优先复用**，不重新推导。
3. 原型 URL 规律（项目已知，直接套用）：框架页 `{原型根}/?id=wlnvrx&p=ablaze_crd`；内容页 `{原型根}/{页面名}.html`（URL 直达）；弹窗 `{原型根}/_1-__app.html?FPopup={弹窗名}&FW=600`（直达或点击触发）；页面名不确定时给候选并标「待人工确认」。

## 执行（三步）

1. 读需求文件，把每个功能点映射到页面或弹窗（列表页/详情页/新建/编辑/删除确认/移动/导入导出/历史版本……）。
2. 交叉功能地图补真实系统侧入口；按 URL 规律拼原型侧地址；触发前置（需选中节点/勾选行/状态要求）并入访问方式一句话。
3. 按「输出格式」落盘并交付，到此为止。

## 输出格式（唯一产物）

```markdown
# {模块} — 原型 × 真实系统 人工对比页面清单

> 生成方式：AI 文本推导（需求 + 功能地图 + 原型 URL 规律），未经浏览器验证，「待人工确认」项以实际打开为准。
> 使用方式：拿到清单后由**用户自行**双开浏览器逐项比对；本清单不向下游流转，差异由用户自行处理。
> 凭据：原型见 inputs/online_prototypes.yaml，真实系统见 .env（清单内不落凭据）。

| # | 页面 | 原型 | 真实系统 | 对比状态（用户自填） |
|---|---|---|---|---|
| 1 | xx列表页 | URL 直达 `{原型根}/xx.html` | 菜单 xx → `/xx` | |
| 2 | 新建xx弹窗 | 点工具栏「新建」触发（直达候选：`弹1-新建xx.html`） | 列表页 → 「新建」按钮 | |
| 3 | 移动弹窗 | 勾选数据后点「移动」触发 | 列表页 → 勾选行 → 「移动」 | |
```

清单规则：

- 仅 5 列：`# / 页面 / 原型 / 真实系统 / 对比状态`。中间两列各写**一句话访问方式**（直达 URL 或点击触发，前置条件并入该句）；「对比状态」列**留空**，由用户比对后自行填写（✓ / ✗ / 简注）。
- 不写需求规则复述、不写差异预判、不加大段备注——保持一眼可扫完的简表形态。
