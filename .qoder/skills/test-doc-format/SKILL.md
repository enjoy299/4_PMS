# 测试点+测试用例 Excel 标准格式

## 参考样例

`output/05_export/工业APP/11-工业APP-测试点+测试用例_20260903_1041.xlsx`

## 文件命名

```
{需求编号}-{模块名}-测试点+测试用例_{时间戳}.xlsx
```

- 需求编号：从 `inputs/requirements/` 文件名提取，补零到两位（如 `11、工业APP.md` → `11`）
- 时间戳格式：`%Y%m%d_%H%M`
- 存放目录：`output/05_export/{模块名}/`

## Excel 整体结构

每个 Excel 文件包含 **两个 Sheet**：

| Sheet | 名称 | 内容 |
|-------|------|------|
| Sheet 1 | `测试点` | 所有测试点 |
| Sheet 2 | `测试用例` | 所有测试用例 |

---

## Sheet 1: 测试点（8 列）

### 字段定义

| 列 | 字段名 | 说明 | 取值范围 | 示例 |
|----|--------|------|----------|------|
| A | 测试点编号 | 唯一标识符 | TP-{ID前缀}-{三位序号}（未拆分子模块时为 TP-{模块名}-{三位序号}） | TP-知识管理-分类管理-001 |
| B | 模块 | 所属功能模块名称 | 实际模块名 | 分类管理 |
| C | 需求来源 | 对应的需求编号 | {模块缩写}-{序号} | CAT-01 |
| D | 测试维度 | 测试类型分类 | 正向功能 / 异常输入 / 边界值 / 状态流转 / 权限控制 | 正向功能 |
| E | 测试点描述 | 简洁描述测试目标 | 自由文本 | 未选中分类时新建一级分类 |
| F | 优先级 | 测试优先级 | P0 / P1 / P2 | P0 |
| G | 是否依赖确认 | 是否需要依赖确认 | 是 / 否 | 否 |
| H | 备注 | 补充说明 | 自由文本，无则填"-" | 核心流程 |

### 测试维度取值说明

| 维度 | 含义 | 典型场景 |
|------|------|----------|
| 正向功能 | 需求定义的正常行为 | 新建、编辑、删除、查询等正常操作 |
| 异常输入 | 空值、非法格式、超长、重复等 | 名称为空、特殊字符、重名 |
| 边界值 | 长度、数量、范围的上下限 | 128字符、3级层级、首尾节点 |
| 状态流转 | 不同状态下的行为变化 | 编辑中→已入库、版本号变化 |
| 权限控制 | 不同角色的可见性和操作权限 | zgn可见/zjj不可见 |

### 优先级定义

| 优先级 | 含义 | 分配原则 |
|--------|------|----------|
| P0 | 核心主流程/阻塞级 | 核心功能、关键权限、主流程操作 |
| P1 | 重要功能 | 正常功能验证、异常处理 |
| P2 | 边界/补充 | 边界值、低频场景、补充测试 |

### 数据示例

```
TP-知识管理-分类管理-001  分类管理  CAT-01  正向功能  所有分类正确显示分类标识          P0  否  核心功能
TP-知识管理-分类管理-007  分类管理  CAT-05  异常输入  分类名称为空时提示必填            P1  否  -
TP-知识管理-分类管理-009  分类管理  CAT-06  异常输入  名称包含空格时提示不符合规则      P1  是  确认：不允许空格
TP-知识管理-分类管理-010  分类管理  CAT-06  边界值    名称长度为128字符时保存成功       P1  是  确认：名称最大128字符
TP-工业APP-工业APP维护-025  工业APP维护 APP-01,APP-02 权限控制 编辑中APP对zgn可见对zjj不可见 P0 是 补充：权限测试
```

## Sheet 2: 测试用例（13 列）

### 字段定义

| 列 | 字段名 | 说明 | 取值范围 | 示例 |
|----|--------|------|----------|------|
| A | 用例ID | 唯一标识符 | TC-{ID前缀}-{三位序号}（未拆分子模块时为 TC-{模块名}-{三位序号}） | TC-知识管理-分类管理-001 |
| B | 模块 | 所属功能模块名称 | 实际模块名 | 分类管理 |
| C | 需求来源 | 对应的需求编号 | {模块缩写}-{序号} | CAT-01 |
| D | 测试点ID | 关联的测试点编号 | TP-{ID前缀}-{三位序号} | TP-知识管理-分类管理-001 |
| E | 用例标题 | 简洁描述测试目标 | 以"验证"开头 | 验证未选中分类时新建一级分类 |
| F | 优先级 | 测试优先级 | P0 / P1 / P2 | P0 |
| G | 用例类型 | 测试类型 | 正向 / 异常 / 边界 / 权限 / 状态 / 配置 / 数据一致性 | 正向 |
| H | 前置条件 | 执行前必须满足的条件 | 具体条件描述 | 已登录系统，进入分类管理页面 |
| I | 测试数据 | 具体、脱敏、可替换的数据 | 数据描述 | 分类名称"一级分类A"，描述"测试" |
| J | 操作步骤 | 详细操作步骤 | 编号列出 | 1. 点击"新建分类" 2. 输入名称 |

| L | 清理动作 | 用例执行后的数据清理 | 操作描述 | 删除"一级分类A" |
| M | 备注 | 补充说明 | 自由文本 | 核心流程 |

### 用例类型取值说明

| 类型 | 含义 | 对应测试维度 |
|------|------|-------------|
| 正向 | 正常功能的正确行为 | 正向功能 |
| 异常 | 异常输入/操作的系统处理 | 异常输入 |
| 边界 | 边界值场景的验证 | 边界值 |
| 权限 | 不同角色的权限验证 | 权限控制 |
| 状态 | 状态流转的验证 | 状态流转 |
| 配置 | 配置变化的影响验证 | 配置联动 |
| 数据一致性 | 数据变化的一致性验证 | 数据一致性 |

## 代码实现

样式定义（openpyxl）：

```python
from openpyxl.styles import Font, PatternFill, Alignment, Border, Side

# 表头样式
hdr_font = Font(bold=True, color="FFFFFF", size=10)
hdr_fill = PatternFill(start_color="2E75B6", end_color="2E75B6", fill_type="solid")
hdr_align = Alignment(horizontal="center", vertical="center", wrap_text=True)

# 数据行样式
cell_align = Alignment(vertical="top", wrap_text=True)

# 边框
border = Border(
    left=Side(style="thin"), right=Side(style="thin"),
    top=Side(style="thin"), bottom=Side(style="thin"),
)
```
