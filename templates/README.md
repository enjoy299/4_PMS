# 测试用例模板说明

本目录存放测试用例的标准 Excel 模板，AI 设计用例时需严格遵循此格式。

## 模板文件

| 文件 | 说明 |
|------|------|
| `test_case_template.xlsx` | 标准用例模板（13 列，含 P0/P1/P2 示例行） |

## 13 列字段定义

| 列序 | 字段名 | 说明 | 示例 |
|:----:|--------|------|------|
| 1 | 用例ID | 唯一标识，格式 TC-{模块名}-{子模块名}-{三位序号}（未拆分子模块时为 TC-{模块名}-{三位序号}），全局唯一 | TC-知识管理-分类管理-001 |
| 2 | 模块 | 所属子模块名称 | 分类管理 |
| 3 | 需求来源 | 对应的需求编号或章节 | CAT-01 |
| 4 | 测试点ID | 关联的测试点编号，格式 TP-{模块名}-{子模块名}-{三位序号} | TP-知识管理-分类管理-001 |
| 5 | 用例标题 | 简洁描述测试目标，以"验证"开头 | 验证所有分类正确显示分类标识 |
| 6 | 优先级 | P0（核心/阻塞）/ P1（重要）/ P2（边界/补充） | P0 |
| 7 | 用例类型 | 正向/异常/边界/权限/状态/配置/数据一致性 | 正向 |
| 8 | 前置条件 | 执行前必须满足的具体条件 | 已登录系统，进入分类管理页面 |
| 9 | 测试数据 | 具体、脱敏、可替换的数据 | 分类名称"一级分类A" |
| 10 | 操作步骤 | 编号列出，每步一个动作 | 1. 点击"新建分类"\n2. 输入名称\n3. 点击保存 |
| 11 | 预期结果 | 可观察、可判断、可记录的结果 | 创建成功，显示在分类树中 |
| 12 | 清理动作 | 用例执行后的数据清理操作 | 删除"一级分类A" |
| 13 | 备注 | 补充说明 | 核心流程 |

## 优先级颜色规范

| 优先级 | 颜色 | 含义 |
|--------|------|------|
| P0 | 红色 (#FF4444) | 核心主流程、阻塞级场景 |
| P1 | 橙色 (#FFA500) | 重要功能、常见异常 |
| P2 | 绿色 (#92D050) | 边界值、补充场景 |

## 填写要求

1. **每条用例只验证一个主要目标**
2. **前置条件必须具体**，不要写"准备有效数据"这类空话
3. **测试数据必须具体、脱敏、可替换**
4. **操作步骤要能被测试人员执行**，编号列出
5. **预期结果必须可观察、可判断、可记录**
6. **不要把待确认内容写成确定性用例**；如必须覆盖，标记为"探索性/待确认"
7. **不要生成重复用例**
