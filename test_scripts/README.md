# test_scripts/ — 测试执行脚本

这个文件夹存放针对具体模块的 **Playwright 测试执行脚本**，每个脚本用一个 `sync_playwright()` 会话按用例顺序操控浏览器。

## 文件说明

| 文件 | 测试模块 | 用途 |
|------|----------|------|
| `test_项目管理.py` | 项目管理 | 项目列表/分类/项目维护/数据查询用例执行（TC-LIST/CAT/PRJ/QRY） |
| `test_知识管理.py` | 知识管理 | 知识管理模块用例执行（分类管理、知识维护、知识查询） |
| `test_7、知识管理.py` | 知识管理 | 知识管理模块完整测试执行（含分类管理、知识维护、知识查询） |

## 两类来源

- **自动生成**（`test_项目管理.py`、`test_知识管理.py`）：由测试执行流程解析用例后生成的确定性 Playwright 脚本，头部带「自动生成 / 生成时间」注释，步骤写死，适合回归复跑。
- **手写定制**（`test_7、知识管理.py`）：针对具体系统页面结构手工编写操作步骤，步骤确定性，适合稳定回归。

> 与流水线 `agents/tester_agent.py`（解析 `output/03_design/` 用例并现场组织执行）不同，本目录脚本是固化下来的可独立运行版本。

## 运行方式

从项目根目录运行（脚本内的 `APP_URL`、账号密码为硬编码，运行前确认目标环境）：

```bash
python test_scripts/test_项目管理.py
python test_scripts/test_知识管理.py
```
